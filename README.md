# Aventara feedback

Bug reports and feedback for the Aventara release candidates (`@aventara/*@rc` on npm).

Docs: https://aventara-framework.vercel.app

[Open an issue](../../issues/new/choose) and pick the type that fits: a bug, a place you got stuck, or something you expected to exist. One issue per problem helps. Include the version (`npx @aventara/cli@rc --version`), your Node version, and the full error text.

The framework's source is not public; this repository only collects feedback.
